# T3.2 — Format spec

> Read [`_SHARED.md`](_SHARED.md) first. Implementer produces the assets; a separate Reviewer accepts them by inspection (human-in-the-loop).

## Dependencies
All of Wave 1 + Wave 2 (this documents their outputs). Best done after T3.1 too.

## Inputs (read-only)
- The emitted `assets/` resources, `assets/shaders/`, `experiment/shaders/FINDINGS.md`
- `tools/check_md_links.py` (link checker)

## Implementation
Author `assets/FORMATS.md` + `assets/formats/*.md` — one section per resource type:
- field meanings, units, coordinate systems;
- transparency convention (**index 31**);
- **palette-effects matrix**: which effects are shader-doable on RGBA and how — night vegetation
  boost on indices 16–24 needs the **1-bit `highlight_mask`** (not the indexed path);
  cross-link `assets/shaders/` and `experiment/shaders/FINDINGS.md`;
- audio synth model (period table, VBL tempo, envelopes);
- `highlight_mask` format (1 bit/px, index ∈ 16–24, transparency follows 31) under `formats/palettes.md`.

Add T3.2 items to the root `assets/verify.json` (`FORMATS.md` lives at the bundle root): one item
for `FORMATS.md` and one per `formats/*.md` section (`view: markdown`), each with a `look_for`
naming the resource type it must cover.

## Outputs
- `assets/FORMATS.md`, `assets/formats/*.md`
- `assets/verify.json` (T3.2 items)

## Implementer self-check (optional aid)
- Every shipped resource type has a spec section; `check_md_links.py` passes; documented field
  names/units match the real emitted files.

## Manual verification (human, by perception)
Work through T3.2's page in the review app (items from `assets/verify.json`):
1. Skim `FORMATS.md` + `formats/*.md`: every resource type you saw shipped under `assets/` has a
   section, and the prose is clear enough that a porting team could consume the bundle from the
   docs alone.
2. Open one spec section next to its real JSON file (e.g. a sprite atlas): the field names you
   see in the file are the ones documented.
3. Confirm the `highlight_mask` / palette-effects matrix is present and matches the T3.1 README story.
Report ACCEPT/REJECT with any gaps noticed.
