# T1.1 — Palettes extractor

> Read [`_SHARED.md`](_SHARED.md) first. Implementer produces the assets; a separate Reviewer accepts them by inspection (human-in-the-loop).

## Dependencies
T0.1 (`asset_common`), T0.2 (C-array extractor).

## Inputs (read-only)
- `src/fmain2.c` (`pagecolors` :367, `sun_colors` :1569, `fade_page` region color-31 overrides :381-386)
- `src/fmain.c` (`textcolors` :476, `blackcolors` :481, `introcolors` :484)

## Implementation
1. Create `tools/extract_palettes.py`.
2. Extract `pagecolors`, `sun_colors` (`fmain2.c`) and `textcolors`, `introcolors`, `blackcolors` (`fmain.c`).
3. Per-region color-31 overrides from `fade_page` in `fmain2.c`: region 4 = `0x0980`,
   region 9 = `0x0445` (or `0x00f0` while `secret_timer` is non-zero, `fmain2.c:383`; emitted under
   `conditional_regions`), all others = `0x0bdf`.
4. Emit each entry as `{index, rgb4 (0x0RGB Amiga OCS 12-bit), rgba8}` using `asset_common.rgb4_to_rgba8`.
5. Add T1.1 items to `assets/palettes/verify.json` (`view: palette`): per palette file, expected
   entry count plus a few indices (e.g. 0, 16, 24, 31) with their `rgb4`→`rgba8` values and the
   `fmain.c`/`fmain2.c` source citation, so a reviewer can eyeball them in the review app.

## Outputs
- `assets/palettes/{pagecolors,textcolors,introcolors,sun_colors,blackcolors}.json`
- `assets/palettes/region_overrides.json`
- `assets/palettes/verify.json` (T1.1 items)
- `tools/tests/test_extract_palettes.py` (optional aid, not a deliverable)

## Implementer self-check (optional aid)
- Color counts per palette match source; `rgb4`↔`rgba8` consistent.

## Manual verification (human, by perception)
Work through T1.1's page in the review app (items from `assets/palettes/verify.json`):
1. Count badges are green: 32 / 20 / 32 / 53 / 32 entries (`pagecolors`, `textcolors`,
   `introcolors`, `sun_colors`, `blackcolors`).
2. Each palette's swatches and preview PNG match the item's `look_for` (e.g. `blackcolors` all black).
3. The listed `rgb4`→`rgba8` spot values match the cited source lines at a glance.
4. `region_overrides`: the variants differ from `pagecolors` only in color 31.
Report ACCEPT/REJECT with notes.
