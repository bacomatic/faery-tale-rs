# T2.6 — Music + instruments extractor

> Read [`_SHARED.md`](_SHARED.md) first. Implementer produces the assets; a separate Reviewer accepts them by inspection (human-in-the-loop).

## Dependencies
T0.1.

## Inputs (read-only)
- `src/assets/songs` (5,984 B): 28 packed track event streams
- `src/assets/v6` (4,628 B): 8×128B waveforms + 10×256B envelopes

## Implementation
Create `tools/extract_music.py`:
1. `src/assets/songs`: 28 tracks, each `i32 packlen` (**big-endian**) + `packlen×2` bytes of
   `(command, value)` events → JSON (note / rest / set-instrument / tempo / end + loop flag).
   Include the Paula period-table reference.
2. `src/assets/v6`: bytes 0–1023 = 8×128 **signed** waveform samples → `waveforms.json`;
   bytes 1024–3583 = 10×256 envelope tables → `envelopes.json`.
3. **Preview renders** under `assets/audio/music/previews/`: a rough audio render per track
   (event stream + waveforms/envelopes + period table) so the reviewer can recognize each theme
   by ear. Fidelity only needs to be good enough to identify the tune. Non-authoritative;
   ship with the bundle.

## Outputs
- `assets/audio/music/<track>.json` ×28 + `assets/audio/music/previews/*` ×28
- `assets/audio/instruments/{waveforms,envelopes}.json`
- `assets/audio/verify.json` (T2.6 items) — expected 28 tracks / 8 waveforms / 10 envelopes as `counts` + preview file ↔ "what you should hear"
- `tools/tests/test_extract_music.py` (optional aid, not a deliverable)

## Implementer self-check (optional aid)
- BE parse correct; byte count consumed per track == `4 + packlen*2`; 28 tracks tile the file
  exactly; 8 waveforms (128 signed each) / 10 envelopes (256 each).

## Manual verification (human, by perception)
Work through T2.6's page in the review app (items from `assets/audio/verify.json`); **listen to the previews**:
1. Play several track previews (incl. the cued ones): each is recognizable as its
   game theme (title, village, dungeon, combat, …) — right melody, sensible tempo.
2. Sanity: 28 track JSONs + 28 previews; 8 waveforms and 10 envelopes present in the JSON.
Report ACCEPT/REJECT with the tracks listened to.
