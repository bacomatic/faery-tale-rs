# T2.3 — Shadow/collision masks extractor

> Read [`_SHARED.md`](_SHARED.md) first. Implementer produces the assets; a separate Reviewer accepts them by inspection (human-in-the-loop).

## Dependencies
T0.1.

## Inputs (read-only)
- ADF `src/assets/image`, **blocks 896–919** (24 blocks × 512 B = 12,288 B): three 4,096 B mask
  files `mask`/`mask2`/`mask3` (`mtrack.c` diskmap[21–23]). Total size = `SHADOW_SZ`
  (`8192+4096`, `fmain.c:642`); loaded contiguously by `load_track_range(896,24,shadow_mem,0)`
  (`fmain.c:1222`). **Do not read past block 919** — blocks 880–895 before and 920+ after are
  AmigaDOS filesystem data and audio samples respectively.

## Implementation
Create `tools/extract_masks.py`:
1. **192** entries × 64 B (32 rows × 2 B, 1 bit/pixel) from the ADF blocks above.
2. Emit indexed PNG per mask + a JSON describing the bit layout (row stride, bit order, dims).
   Cite the mask-application code in `fmain.c` for how entries are indexed (verify 0–191 direct
   indexing rather than assuming it).
3. Add T2.3 items to `assets/masks/verify.json`: a `count` of 192 mask PNGs and the contact
   sheet, with a **source-derived `look_for`** and the usage breakdown from the terra data
   (`masks.json.usage`: which entries the game can apply, which have pixels but are never
   referenced, which are blank), so a reviewer can view them in the review app and confirm.

## Outputs
- `assets/masks/*.png` + bit-layout JSON
- `assets/masks/verify.json` (T2.3 items: file ↔ source-derived description)
- `tools/tests/test_extract_masks.py` (optional aid, not a deliverable)

## Implementer self-check (optional aid)
- Bit layout round-trips (PNG→bits == source bytes); 192 entries; spot-reconstruct entry 0 and
  entry 191 by hand from the raw ADF bytes.

## Manual verification (human, by perception)
Work through T2.3's page in the review app (items from `assets/masks/verify.json`):
1. Confirm 192 mask PNGs, each 16×32 (or as documented).
2. Look at a spread of masks (incl. the described ones): the shapes read as plausible
   terrain/object occlusion silhouettes (tree canopies, building edges, …) — not noise.
Report ACCEPT/REJECT with the entries viewed.
